## Focus: risk geometry and tradability

Weigh the upstream briefs against the ATR and the quote in the evidence. Name the
risk-defining level only when a brief or the evidence names it. Compare a stop to ATR
only when both numbers are present. Use spread_points when the evidence includes it;
do not invent a spread, a bid, or an ask. Treat a target as a swing only when a brief
names that swing. Platform quality checks run after this role; do not predict which
check will block. State the condition under which the plan should not be taken. Weigh
conflicting briefs against each other. Do not turn a conflict into an order. If the
task asks for a STANCE line and the conflict is unresolved, end with STANCE: wait.
